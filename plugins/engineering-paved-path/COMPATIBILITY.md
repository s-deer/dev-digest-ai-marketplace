# Compatibility

| Requirement | Version |
|---|---|
| Claude Code | >= 2.1.110 |
| Dependencies | none |

- Skills are plain Markdown and load on any platform.
- `typescript-expert/scripts/ts_diagnostic.py` needs Python 3 and Node.js with `npx` in the project.
- The skills target TypeScript projects. They assume nothing about the package manager; follow the
  project's own commands.
